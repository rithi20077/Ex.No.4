# Active Prompting

# Prompt:

"Act as an AI assistant for designing an IoT-based predictive maintenance system. Ask one important question at a time. Based on each answer, ask the next relevant question. Continue until enough information is collected. Finally, provide a customized smart manufacturing solution."
Answer:

AI: What type of manufacturing machines need to be monitored?

User: CNC machines.

AI: Which parameters should be monitored?

User: Temperature, vibration, and energy consumption.

AI: Is real-time remote monitoring required?

User: Yes.

AI: What is the main objective of the system?

User: To reduce machine downtime and improve production efficiency.

# Final Answer

The proposed system will use IoT sensors to monitor temperature, vibration, and energy consumption of CNC machines. Embedded controllers will collect and process the sensor data and send it to a real-time monitoring platform.

The system will detect abnormal machine conditions and generate alerts for the maintenance team. Predictive maintenance will help identify possible failures before they cause unexpected downtime. Energy consumption will also be monitored to identify inefficient operations and improve energy efficiency.
